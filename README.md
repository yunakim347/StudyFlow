# StudyFlow

A native macOS study-planning app built with SwiftUI and SwiftData.

Inspired by the Timetable app. This project reimplements a similar
class-timetable and task-tracking experience from scratch, built as a
personal exercise in native SwiftUI/SwiftData app architecture.

## Features
- Classes, Tasks, and Exams navigation
- Day, week, and month timetable views
- Add and edit classes, with full class detail screens
- Search across classes and tasks
- Due-date tracking for tasks and exams
- Weekend toggling and adjustable schedule layout

## Built with
- Swift
- SwiftUI
- SwiftData
- Xcode
